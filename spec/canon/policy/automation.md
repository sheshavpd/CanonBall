# Who decides what

People own this page. It records how far each kind of decision has been handed to agents, from
0 (agent analyzes, a person decides) to 5 (agent acts, people watch the metrics). A setting moves one
step at a time, on track record, never because a new model was released.

| Kind of decision | Level |
|---|---|
| What the system promises | 1, and stays with people |
| What is never allowed | 1, and stays with people |
| Choices a customer would notice | 1 |
| Architecture | 1 |
| Detailed design | 1 |
| Verification design | 1 |
| Decision logic (code with no side effects) | 1 |
| Code that touches the outside world | 1 |

Review has no level. An agent reviews every change; `review.md` says when a person reviews as well.
